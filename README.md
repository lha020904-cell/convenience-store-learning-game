# 🏪 도전! 편의점 쇼핑왕 (특수학급 중학생 편의점 경제 교실)

특수학급 중학생의 일상 자립 생활 역량 강화를 위해 설계된 **맞춤형 편의점 물건 구매 교육용 웹 시뮬레이션 게임**입니다.

---

## 🌟 기획 및 교육 목표

- **대상**: 특수학급 중학생 및 일상 자립 생활 훈련이 필요한 학생
- **목표**: 편의점 환경에서 실제 일어나는 쇼핑의 전 과정(가격표 읽기, 구매 목록 확인, 물건 고르기, 점원과의 의사소통, 화폐 및 교통카드 결제, 영수증 확인)을 단계별로 체험하여 자립 생활 능력을 향상합니다.

---

## 🚀 주요 기능

### 1. 수준별 3단계 학습 코스
- **🌱 새싹 1단계 (기초)**: 물건 1~2개 선택, 큰 그림 목록, 1,000원 단위 또는 청소년 교통카드 터치 결제
- **🌿 쑥쑥 2단계 (중급)**: 물건 2~3개 선택, 500원·100원 동전과 지폐 조합 계산, 비닐봉투 필요 여부 대화
- **🍎 열매 3단계 (실전)**: 5,000원 예산 내 구매, 1+1 행사 상품 이해, 거스름돈 직접 계산 및 영수증 확인

### 2. 실제 편의점 쇼핑 시뮬레이션
1. **미션 브리핑 & 장바구니**: 구매 목록과 예산을 확인하고 진열대(음료, 삼각김밥, 라면, 과자, 아이스크림) 탐색
2. **가격표 읽기 & 음성 지원**: 가격표 숫자 확인 및 한국어 음성(TTS) 읽어주기
3. **계산대 바코드 스캔**: 스캐너로 각 상품을 직접 '삑!' 소리와 함께 스캔
4. **점원과의 의사소통**: 인사하기, 비닐봉투(100원) 선택, 영수증 받기 롤플레잉
5. **화폐 결제**: 10,000원·5,000원·1,000원 지폐와 500원·100원·50원·10원 동전 올리기 또는 교통카드 결제

### 3. 특수교육 접근성 특화 UI
- **크고 단순한 버튼**: 최소 56px~64px 높이, 굵고 선명한 글씨와 명확한 테두리
- **실제 상품 및 화폐 실물 사진**: 바나나우유, 삼각김밥, 컵라면, 샌드위치 실제 상품 사진 및 실제 한국 동전·지폐 사진 적용
- **시각적 안정성**: 과도한 깜빡임이나 산만한 애니메이션을 배제하고 차분한 조작감 제공
- **시간 여유 모드**: 3분 타이머 권장 모드 외에 조급함 없이 학습할 수 있는 여유 모드 스위치 제공

### 4. 성취감 보상 & 수료증
- 미션 클리어 시 축하 효과 및 코인 획득
- **'참 잘했어요' 5구 스탬프 북** 및 달인 뱃지 6종 도감
- 학생 이름을 입력해 바로 인쇄할 수 있는 **「편의점 쇼핑 달인 인증서」** 발급

---

## 🛠️ 기술 스택

- **Framework**: React 19, TypeScript
- **Styling**: Tailwind CSS v4
- **Audio**: Web Audio API (경쾌한 BGM 및 편의점 차임·바코드 비프음 합성) & Web Speech API (한국어 음성 TTS)
- **Icons**: Lucide React
- **Celebration**: Canvas Confetti
